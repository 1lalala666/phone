# 手机评论情感分析交互式看板

基于京东手机商品评论数据的交互式可视化看板，对 2322 条真实用户评论进行情感挖掘与分析。

## 项目概述

本项目以「用数据讲故事」为核心，将情感分析成果产品化，打造一个任何人都能在线浏览的交互式数据看板。看板整合了描述性统计、假设检验、情感分析、词频分析与回归建模的结果，将复杂的分析结论转化为直观、可交互的可视化界面。

## 数据来源

- 数据集：ChineseNlpCorpus 公开数据集（online_shopping_10_cats）
- 数据量：2322 条手机类别用户评论
- 关键字段：评论内容、情感标签（正向 / 负向）、评论长度

## 看板功能

- **核心指标卡片**：评论总数、正负向占比、平均长度、情感分析准确率
- **交互式图表**：基于 Plotly.js，支持悬停查看数值、缩放、筛选
- **多维度分析**：情感分布、评论长度、SnowNLP 情感打分、高频词对比、相关性热力图
- **核心发现**：5 条关键洞察，以卡片形式呈现
- **特色功能**：暗色 / 亮色主题切换、滚动动画、分析方法流水线、样本评论展示

## 技术栈

- 前端：HTML5 + CSS3 + JavaScript（单文件内嵌，可离线运行）
- 图表库：Plotly.js
- 数据处理：Python pandas / SnowNLP / jieba / scipy / scikit-learn
